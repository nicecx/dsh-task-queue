## 制度条款（写入契约「四·十一 lesson 主动触发」）

1. **触发场景清单**（满足任一 → 必须 lesson）：
   - 关卡/机制被绕过（如 009：异常放行、导入缺失）
   - 审批链异常（裁决失效/静默放行/fail-closed 误判）
   - 队列/消费端卡死或误判（如 fire 锁陈旧、单槽污染）
   - 部署事故（sed 静默失败类、重启失败、健康检查异常）
   - 数据/安全事件（权限绕过、凭据风险、不可逆操作）
   - 告警风暴或反复误报（如 swap 阈值误报链条）
   - 任何 S1/S2 级缺陷修复完成后

2. **自动提审流程**（无需用户确认）：
   - 事件确认后 **24h 内** lesson_review_submit 提审（title/incident/rootCause/lesson/defectPattern 必填）
   - defectPattern 必填（传播扫描依赖；可后续优化提取质量）
   - changeFiles 填实际修复源码路径（009 审核非阻塞观察）

3. **闭环衔接**：
   - approved → 守则追加（OPS-GUARDRAILS）+ 传播扫描（已有）
   - changes-requested/rejected → 修订重提（同互审流程）
   - 修复验证后更新 KNOWN-ISSUES（open→fixed→verified）

4. **遗漏问责**：每日收盘核对（004 已有 schedule 纪律）顺带检查"当日 S1/S2 事件是否已 lesson"；遗漏 → 补提 + audit 记录
